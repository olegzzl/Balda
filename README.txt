БАЛДА ГРИН — локальный комплект (игра + коннектор к чату YouTube)
============================================================

ЧТО ПОНАДОБИТСЯ ЗАРАНЕЕ
  - Компьютер на Windows 10/11 (подойдут также macOS или Linux).
  - Установленный Python 3.10 или новее: https://www.python.org/downloads/
    На Windows при установке отметь галочку «Add python.exe to PATH».
  - Для настоящего чата YouTube — свободные ~10 минут на настройку ключа
    (шаги ниже) и запущенный или запланированный стрим с активным чатом.

ЧТО ВНУТРИ
  game/                          сама игра (зелёная версия онлайн-прототипа)
  connector/yt_balda_connector.py  программа-коннектор
  connector/config.example.txt   заготовка настроек

ПРОВЕРКА БЕЗ YOUTUBE (ничего настраивать не нужно)
  1. Открой терминал (на Windows: Win+R → cmd) в папке connector.
  2. Запусти:   python yt_balda_connector.py --demo
     (на Windows может быть «py» вместо «python»).
  3. Открой в браузере:  http://127.0.0.1:8765/
     «Зрители» сами начнут писать слова — видно, как игра принимает
     ходы, ставит буквы и считает очки. Остановка: Ctrl+C в терминале.

НАСТОЯЩИЙ ЧАТ YOUTUBE (один раз, ~10 минут)
  1. Зайди на https://console.cloud.google.com под тем же Google-аккаунтом,
     что и твой YouTube-канал.
  2. Создай проект (любое имя).
  3. Включи «YouTube Data API v3» (кнопка Enable/Включить).
  4. Открой «APIs & Services → Credentials» → «Create Credentials» → «API key».
     Скопируй ключ.
  5. Ограничь ключ: в списке ключей открой созданный → «Restrict key» →
     в «API restrictions» выбери только «YouTube Data API v3» → Save.
  6. В папке connector скопируй config.example.txt как config.txt и впиши:
         API_KEY=<твой ключ>
         VIDEO_URL=<ссылка на твой стрим>
  7. Установи зависимости (один раз), в терминале из папки connector:
         pip install -r requirements.txt
  8. Когда стрим активен:
         python yt_balda_connector.py
     и открой http://127.0.0.1:8765/ — слова зрителей попадут в игру.

OBS
  OBS только показывает картинку: добавь источник «Окно» или «Браузер»
  на окно с http://127.0.0.1:8765/ и веди трансляцию как обычно.
  Чат читает не OBS, а коннектор.

БЕЗОПАСНОСТЬ КЛЮЧА
  - Ключ API живёт только в твоём config.txt на твоём компьютере и
    отправляется напрямую серверам Google. Он не попадает на страницу
    игры, в ленту сообщений и в обычные сообщения программы.
  - Коннектор слушает только 127.0.0.1 — страница доступна лишь с этого
    компьютера.
  - Ключ — как пароль: никому не показывай. Если засветил — удали его
    в консоли и создай новый.

КВОТА
  Чтение чата идёт одним потоковым подключением (streamList): одно
  подключение стоит 5 единиц при стандартном лимите 10 000 единиц в день,
  сообщения внутри потока новых списаний не создают.

ОТЛИЧИЯ ЗЕЛЁНОЙ ВЕРСИИ
  - Тёмно-зелёный фон, кремовые плитки, горчичная подсветка слова.
  - В админке: настройка цвета фона, выключатель звёзд и имитация
    живого чата (сообщение каждые 2-3 секунды, примерно треть слов
    реально встаёт на поле). Всё включается кнопками в панели «админка».
  - Это отдельный проект: исходная (индиго) Балда не изменялась.
